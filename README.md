### What I'm building

| System | What it is | State |
| :--- | :--- | :--- |
| **Uniformity OS** | Local-first coordination backbone — identity, shared object state, evidence, action, verification, history. | `91 / 91 tests passing` |
| **RESELL** | Resale-domain system. Transaction and resale truth, kept deliberately separate from coordination. | `active` |
| **SUBANGEL** | Calm intelligence layer for musicians, instrument builders, repairers and recording spaces. | `building` |
| **FreeBuff** | SaaS API platform — auth, billing, products, users. | `active` |

---

### How I work

- **One owner per truth.** Coordination, product and runtime data never collapse into each other.
- **Evidence over assertion.** Every claim carries a command, a result and a timestamp.
- **Separate by design.** Systems compose through contracts, not shared databases.
- **Progress you can measure.** Working artifacts, not descriptions of them.
