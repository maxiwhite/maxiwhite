### What I'm building

| System | What it is | State |
| :--- | :--- | :--- |
| **[Uniformity OS](https://github.com/UNIFORM1TY/uniformity-os)** | The operating system / composition layer. Identity, canonical object state, evidence, action, verification, history. | `91 / 91 tests passing` |

### How I work

- **One owner per truth.** Coordination, product and runtime data never collapse into each other.
- **Evidence over assertion.** Every claim carries a command, a result and a timestamp. Staging is not verification.
- **Separate by design.** Systems compose through versioned contracts, not shared databases.
- **Boundaries stay explicit** even when the experience feels seamless.
